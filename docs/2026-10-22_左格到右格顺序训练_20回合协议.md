# 左格到右格顺序训练：每条指令20回合

**通俗说明：保留已经会放左格的模型，接着只教它放右格。然后用完全相同的20个场景分别问“前／左／右／后”，看右格是否学会、旧左格是否保留、还是旧左格指令也被带成了右格。**

本轮已获用户授权，采用纯顺序微调，固定终点；它是单旧技能保持与新目标偏置的最小实验，尚不等同于多目标语言分辨机制研究。

## 1. 固定设置

| 项目 | 本轮规则 |
|---|---|
| 初始模型 | `outputs/r0/single_left_20261022_01/checkpoints/006000`，完整加载权重及处理器 |
| 新任务 | 同场景把书放入右格，与旧左格构成直接目标对照 |
| 训练数据 | 仅右格40条训练、10条验证，沿用既有轨迹划分及正确时序配对 |
| 回放 | 无左格回放、无蒸馏，本轮先测纯顺序微调 |
| 归一化 | **继承左格起点的状态／动作统计，不切换成右格统计** |
| 更新范围 | 沿用原模型：冻结VLM，更新动作专家与相关投影 |
| 优化 | 重新建立AdamW及调度器，batch6、lr1e-4、warmup100、BF16、seed20261021 |
| 预算 | 在左格6000步之上再训练右格6000步；新运行编号从0开始计数，保存1000步间隔 |
| 选点 | 只评估固定的右格+6000步终点，不根据旧任务下降或新任务高分挑检查点 |
| 控制 | chunk50、flow10、执行10步，20Hz；每回合400控制步 |
| GPU | GPU0训练；GPU1先评估冻结旧起点，训练结束后评估续训终点 |

实现使用既有数据入口的 `old_goals: ["right"]` 字段表示“本轮训练数据只有右格”；研究语义上的旧任务仍为左格，新任务为右格，由 `sequential.old_goal/new_goal` 明确记录。

这里的“从旧模型开始”不是恢复旧训练日志：旧模型权重和归一化继承，优化器／学习率调度重新开始。原左格检查点保留不变，记录模型哈希；终点前后检查归一化张量内容一致。

## 2. 每条指令20回合，训练前后配对

- 每个模型都评估前／左／右／后四条指令，每条20回合，共80回合；训练前后合计160回合。
- 使用初态30—49，同初态的四指令及两个模型共享完整物理状态、canonical XML和推理种子。30—39已在上一轮使用，40—49首次进入这轮探测，不宣称整组都是全新测试集。
- 开发0—9不用于本轮终点评估，资格10—29仍未使用。原保留40—49此次已消耗，不再称保留集。
- 每个回合同时记录请求目标曾成功、首次目标、最终目标、未完成／歧义，以及是否曾成功后又被破坏。
- 保存全部逐回合及逐步记录；每个指令保存第一个初态的视频。不会因失败删除回合。

## 3. 先看右格学到没有，再解释左格变化

1. 对照训练前后右格20回合正确成功率。预先设16/20“过程曾成功”为描述性高成功率门槛；无论是否达到，均保留固定终点结果。这不是统计证明或独立资格验收。
2. 对照左格20回合的过程及终态成功率。只在训练前左格确实成功的相同初态上，另外报告保留与损失，避免把起点本来不会的状态算成遗忘。
3. 对损失回合分开记录：旧左格指令转成新右格、其他错误目标、未完成、歧义。曾经完成左格再丢失结果，与始终没有完成左格分开。
4. 查看前／后两条未训练指令的目标矩阵，判断原左格默认输出是否变成右格。它们的失败仍不计为遗忘。

预期可能出现的结果及解释：

- **右格学会、左格转右格**：支持单旧技能在顺序适应后出现新目标替代的候选现象；仍需复现、对照和后续机制验证。
- **右格学会、左格主要未完成**：更接近普通技能损伤，不能硬写成目标替代。
- **左右均成功**：说明这轮顺序训练可能保留甚至获得指令条件选择，不能为了预期现象继续调到它坏掉。
- **右格没有明显学习增益**：先诊断新任务学习，本轮不足以证明“学新导致忘旧”。

## 5. 归一化检查误报与固定终点补评

原流程于18:55左右完成6000步训练，训练本体25分24秒；训练前80回合也已完成，左格终态19/20。随后在终点评估前触发 `Normalization changed across tasks`，没有执行训练后回合。启动时的预计完成时间因此没有兑现。

21:26恢复SSH读取后，逐张量诊断发现：预处理器保存时，部分计数和索引标量由形状 `[1]`（少数为 `[1,1,1]`）转为标量 `[]`；后处理器没有差异。原检查将形状直接写入哈希，把这种单元素存储变化误判成了统计变化。

修复仅对单元素统计的形状做等价化，仍严格检查统计名称、dtype、数值和非单元素形状；并额外验证：

- 两模型处理器JSON配置一致。
- 归一化统计在单元素形状等价化后完全一致。
- 相同输入下，两个处理器产生的动作、状态、两路图像、语言token及mask完全一致，反归一化输出也完全一致。
- 父模型哈希不变；6000步训练已完成、保存重载通过、冻结参数保持不变。

因此该中断属于检查误报，不需要重新训练。原 `run_summary.json` 的失败记录完整保留。21:33:47开始用冻结的同一+6000终点补评；两张空闲3090分别负责前／左与右／后，每条仍20回合，合并时核验全部80个条件。训练源码为 `2b0022d`，补评源码为 `c078cc2`；未改变轨迹生成逻辑、初态、指令、步长或选点规则。
