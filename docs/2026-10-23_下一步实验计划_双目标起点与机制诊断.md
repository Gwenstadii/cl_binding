# 下一步实验计划：先学会听懂两条指令，再研究持续学习为什么把目标弄混

**通俗说明：目前机器人更像“最近练哪个格子，就把书往哪个格子送”，还没有证明它曾经能够同时听懂两条不同指令。下一步先让同一个机器人学会“放左格”和“放前格”，换指令就能换目标；再教右格，看它是否把原本会分辨的目标弄混。先检查普通复习能否解决，确有残留问题后，才研究哪里的信息传递变了，以及怎样用少量记忆和蒸馏保护它。**

2026-10-23。本文是待执行计划，本轮不启动训练。使用现有双3090、SmolVLA和已核验的LIBERO SCENE2数据；保留既有顺序链及其结果，建立一条独立的新协议。结果依据见[实验记录E004、E005](../实验记录.md)。

## 1. 当前知道什么，下一步必须补什么

- 左→右→前已出现明确的最新目标偏置：原右格成功的15个初态，学前格后12个最终到前格、3个未完成。
- 学后格后，请求后格17/20曾成功，但最终只有3/20正确。现评估成功后仍执行至400步，不能将85%写成稳定掌握，也不能仅由15%判断从未会做。
- 整条旧链尚无一个模型同时高成功地区分两个已训练目标。因此，目前支持“单旧技能丢失及最新目标偏置”，尚未证明“已经获得的多目标语言选择能力衰退”。
- 当前冻结整个VLM，直接更新动作专家及状态／动作／时间投影，实际可训练参数99,880,992；没有使用LoRA，也不是整个VLA全量微调。没有进行LoRA优劣对比，不能把当前选择解释成已经证明LoRA不适合。

**这轮最重要的交付是一个合格双目标起点，以及对“普通回放后是否还有值得解释的选择损伤”的明确判断。**

## 2. 第一步：先解释现有后格成功为什么保持不住

本轮已经完成20条后格轨迹的首次／最后成功、最长连续成功、成功区间和终态统计，见[逐条诊断](results/2026-10-23/visual_cases/back20_temporal_diagnostics.json)与[视频图解](results/2026-10-23/visual_cases/视频解读.html)。14条成功后失效中12条最终未完成、2条其他格；17条曾成功中16条从首次成功到结束夹爪命令始终为正，是释放／结束控制的线索，不是接触状态或因果证明。接下来优先对14条失效逐条归类物体与夹爪动作，不重复统计为新评估。

| 要检查的情况 | 应查看的证据 | 可以先做的判断 |
|---|---|---|
| 只短暂经过目标区，仍夹着书 | 成功区间短，夹爪与物体随后继续移动，录像未见可靠放稳 | 到达判据不等于完成放置 |
| 放下后又接触、搬走或碰倒 | 先有成功区间，随后物体明显移动，录像能对应后续动作 | 成功后的行为破坏了结果 |
| 松爪后滑落或放置不稳 | 释放附近失去成功，物体位移与画面一致 | 优先检查释放与接触控制 |
| 从未满足后格 | 全轨迹后格谓词为假 | 单列学习／执行失败，不能用停止规则解释 |

“14条曾成功后失效”和“14条终态未完成”是不同集合，必须逐条对应。几何位置、夹爪指令和成功谓词都不足以单独证明物体已经释放并放稳；存在遮挡时标为待判定。

若录像与记录仍无法区分，先做一个小型控制：**同一后格12000步权重、相同初态和随机种子，比较每次执行10步与1步后重新预测**，最多开发初态0—9各10回合。保持400步时限，另外报告成功持续时间、推理次数与耗时。它检验反馈频率的影响，不是新的训练方法。不要用“成功即停止”替换原诊断终点；原生成功指标与保持指标分开保留。

本步产物：逐回合分类、2—3个可核查案例，以及是否值得调整执行频率／释放训练的结论。没有证据前不默认“再加12000步”。

## 3. 第二步：建立“左＋前”双目标起点R0

### 3.1 数据与训练

1. 从原始`smolvla_base`重新开始；左格40条＋前格40条训练，共80条；各10条验证，共20条。沿用已核验的观测→下一动作对齐、双相机、指令文本、20Hz及轨迹划分。
2. **只用这80条联合旧训练数据计算一份新的状态／动作统计并锁定。** 验证轨迹、右格数据和评估初态不进入统计。后续全部分支继承这份归一化，不重新计算右格统计替换它。这与历史链的左格归一化是不同协议，不把两条链直接当单因素消融。
3. 冻结VLM，训练范围沿用当前动作专家与相关投影；batch6中左／前各3条记录，lr1e-4、warmup100、chunk50、flow10、每次执行10动作。先保持这些已有设置，避免同时改模型、执行和采样。
4. 预先固定6000／12000／18000步候选，最多18000步；按顺序检查，满足开发门槛就冻结第一个达标点。开发失败不翻查任意中间点挑最高分。
5. 保存权重、优化器／调度器／随机状态、数据划分、归一化、可训练参数名单、训练日志、严格重载结果与冻结参数哈希。

### 3.2 怎样才算听懂了两条指令

开发初态固定为0—19。在每个**完全相同的物理初态**分别给左／前指令，固定场景XML、种子、动作缓存清空方式和400步时限，共40回合。不能把不同任务文件的同编号默认成同状态。

候选通过须同时满足：左格终态正确≥16/20、前格终态正确≥16/20，且**同一初态的两条指令都终态正确≥16/20**。第三项防止两条指令分别只在互不相同的一部分状态上成功。另报过程曾成功，不用它替代终态门槛。

候选冻结后，才使用此前未用于选择的20—29初态，**只做一次**独立工程资格检查：左／前各10回合，逐目标及同初态双指令同时终态正确均≥8/10。这个小样本门槛不等于证明总体成功率超过80%。

- 开发至18000步仍失败：停止后续FT／ER和新方法，检查联合条件学习与操作问题；不无限追加预算。
- 开发通过、资格失败：如实记为未合格，不能用资格成绩回头挑另一个候选再刷。若重新设计，先回开发流程，下一次独立确认另准备未使用状态。
- 两者均通过：命名并冻结`R0-left-front`。在同一资格初态补测右格10回合，作为右格更新前水平；原始基座的预训练接触未知，称“本轮R0未适配右格”，不称严格未见技能。

旧30—49初态已被反复查看，只用作历史可视探测，不改称新的独立测试集。资格集此后可以做预先锁定的前后配对，但不能再用来调参或选择方法。

## 4. 第三步：只加一个右格新任务，先比较三条基础路线

三条路线从同一合格R0权重／处理器出发，使用同一代码与评估条件。新任务仅右格40条训练、10条验证；后格暂不进入本轮训练。R0权重继续封存。

| 路线 | 训练安排 | 作用与预期边界 |
|---|---|---|
| 冻结R0 | 不训练，复用条件完全相同的缓存评估 | 排除起点本身不会、评估漂移或随机条件变化 |
| FT | 仅右格，batch6，固定12000步 | 测无回放的损伤边界；可能错目标，也可能只是操作变差或不遗忘 |
| 普通ER | 每步4条右格＋1条旧左格＋1条旧前格，batch6，固定12000步 | 测有限普通复习能保住多少；它也可能已经足够解决问题 |

FT／ER都用相同lr1e-4、warmup100，在R0边界以同一规则新建优化器，后续保存／评估不重启它；统一在3000／6000／9000／12000保存。终点固定，不按旧题哪次最差挑结果。开发曲线用于观察新任务是否学到，不改变本轮终点。

**记忆先用简单规则：** 在R0阶段从训练集按旧目标等量、目标内均匀随机抽取记录，固定种子；先导上限左／前各256条，共512条。每条包含自包含的两张图、状态、真实指令、真实动作块及mask、必要来源信息，不能靠索引免费访问未计费的旧视频。导出后记录实际总字节B；切换到右格后，ER只读取这份记忆。该规模是预设先导预算，不是已经证明充分。

两条训练路线都做12000次batch6更新，匹配总更新与总样本处理量；**新任务曝光不同**：FT每步6条新样本，ER每步4条。不能把两者称成新数据曝光完全一致。报告学习曲线及新旧折中；需要隔离新任务曝光时，再预先加一条FT每步4新样本的辅助参照并披露计算差异。以后ER与候选回放必须严格匹配batch组成、更新、记忆字节及新任务曝光。

资格初态20—29在三个模型上分别评估左／前／右，共90回合；其中R0左／前20回合已在资格阶段完成，条件一致时直接复用，不重复计数。全部400步，不因低成功率重跑；运行崩溃另记并按同一规则补齐。过程成功和固定终态分列，若另跑原生成功即止协议，单独列出新增执行量。

主要输出：每目标正确／错到右格／错到另一旧格／未完成／歧义；“原来正确→后来新目标”的逐初态转移；先正确后破坏单列；右格学习增益及操作质量。主分母包括全部配对，另列R0原来正确子集，不能只选训练后表现好的状态。

| 实际结果 | 下一步决定 |
|---|---|
| 右格没有明显学习增益或仍大量未完成 | 先解决新任务学习；不宣称已达到良好保持—学习折中 |
| 仅FT明显坏，普通ER稳定 | 接受普通ER在当前预算下已够用；不宣称普通回放仍有难解缺口 |
| ER学会右格，旧指令仍出现多例新发错目标 | 用独立训练起点复验，再进入功能／通路诊断 |
| 主要是抓空、掉落、放置失败 | 优先执行阶段诊断，不强行归为语言选择失效 |
| 各路线均稳定 | 当前最小设置不支持主要损伤假设，收窄或调整问题；不通过缩小记忆等手段追求必然坏掉 |

## 5. 第四步：有信号后，才追问“哪条路径变了”

先以第二个独立训练种子重建R0与FT／ER，复验同类变化；换评估seed不能代替独立训练。然后分两层做，不把输出算术当内部通路结论。

1. **先分功能。** 准备书已抓稳、还未进入任一格的共同状态，先验证R0能按左／前分别完成，再比较更新模型；区分早期抓取问题与后段选择问题。中间状态结果不代替完整任务成绩。
2. **保留v3原有响应交换。** 同一状态、指令集合、噪声动作及生成时间，把输出拆成两条指令的平均响应和各自相对平均的区别；在开发锁定的选择窗口比较换旧平均、换旧区别、两者都换。补自替换、错误指令区别、等范数随机修正、当前区别放大，以及健康R0背景注入新响应的反向检查。救回一次只称补偿，不直接叫成因。
3. **再检验内部候选路径。** 预先登记三个候选：动作专家读取VLM条件的注意力接口变化；状态投影改变条件竞争；动作读出／运动策略覆盖。用固定状态下的模块或激活交换逐项检查，包含反向破坏和无关交换；修复须改变对应错目标，且不能靠破坏操作或不学右格取胜。交换整块模块成功也不等于已经定位其中某条信息边。

VLM权重冻结，只排除了本轮直接改写VLM权重；后续可训练接口仍可能改变如何使用条件。仅能从隐藏状态读出“左／前”文字，也不等于目标被正确接地或用于控制。支持“信息仍在但未被使用”需要同状态行为、内部干预与操作保留共同证据。

## 6. 第五步：保留回放与蒸馏候选，但受前置证据约束

本节继承本地`essay/v3_实验.md`第六至九步的候选，不改原蒸馏思想。该本地稿不入Git，下面将必要规则完整写出，便于服务器端阅读。

- **原蒸馏候选：** 同一合法旧状态固定画面、机器人状态、噪声与生成时间，让学生保留R0“换左／前指令时动作应怎样改变”的区别；允许共同响应变化。仍保留真实动作回放。若共同响应偏移或执行损伤主导，应改保护对象或收窄主张，不能硬用差分保护。
- **条件区别覆盖回放：** 趁旧训练数据还可访问，在合格R0上选互补的完整状态；依据条件响应对小幅参数变化的敏感性，减少最弱目标区别的约束盲区，另保留抓取／释放等操作覆盖。先小候选池计时，不把局部敏感性称为未来遗忘概率。只在能合法比较两条指令、R0确实会的状态上做条件约束。
- **记忆必须真受限：** 图像、状态、真实动作、教师缓存、索引全计入B字节；切换后不能重开全套旧数据。没有另一指令的真实动作标签，就只做教师约束，不能复制原动作给新指令。输入、噪声或预处理变化时重算对应教师目标。

先做A随机ER、B随机状态＋原蒸馏、C覆盖选样ER、D覆盖选样＋原蒸馏。因素分析中A/B用同一真实记录，C/D也用同一入选集合，仅切换蒸馏；另列真实等字节比较，允许无缓存的ER多存数据。**D必须优于B，才支持选样在同一蒸馏上的额外收益；C无收益时不能称普通回放本身被改进。**

只有普通ER残留可复验选择损伤、干预支持对应保护对象，才实现上述候选；否则暂缓。候选有信号后再加完整输出蒸馏及关键状态／干扰／多样性选样，正式结论再扩到至少三个训练种子、多个记忆预算和未用于设计的新目标族。不把“配对、蒸馏、选难题”本身写成已经建立的独立创新。

**LoRA安排：** 最小FT／ER跑通后，若需检查参数化影响，从同一R0另开动作专家LoRA对照，VLM仍冻结；导出准确目标模块、rank及额外可训练投影，不能只改标签。先比较能否学好右格与保持折中，再决定是否作为主适配方式，不预设LoRA一定防遗忘。该实现与训练另计。
