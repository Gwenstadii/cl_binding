# 第二阶段训练计划：有限普通回放能否保住目标选择

**通俗说明：机器人已经出现“最近学哪个格子，就把旧指令也做成那个格子”的现象。下一步把它退回还能区分左／前指令的封存模型，让它一边学右格、一边复习少量左／前旧题；另设一组只学同样数量右格新题的对照，检查收益到底来自复习，还是仅仅因为新任务学得少。先得到这个答案，再决定要不要研究具体的信息传递路径和新回放方法。**

整理日期：2026-10-24。**状态：计划已形成，第二阶段训练尚未启动。** 本文承接[第一阶段总结](../实验记录.md#phase1-summary)，是下一阶段的新协议；此前顺序实验及资格规则保持原记录。

## 1. 本阶段先回答什么

首批只回答两个问题：①固定有限旧记忆后，普通随机回放能否减少旧指令的新目标替代？②保持收益是否伴随新右格无法学好？

第二阶段分为三个推进步骤：

| 步骤 | 工作 | 产物与边界 |
|---|---|---|
| 2A：普通回放先导 | 复用封存双目标模型，只学右格，跑FT匹配对照与普通ER | 低成本判断回放是否有用，仍属探索 |
| 2B：正式起点与复验 | 独立确认合格R0，锁新物理状态，重跑常规FT／匹配FT／ER | 检查是否有可复验且非未学新任务换来的保持收益 |
| 2C：按证据进机制与保护 | 小型功能／通路干预，再决定原蒸馏及互补选样 | 没有残留缺口或特异证据时收窄主张 |

**第一笔实际训练建议是2A的两条分支。** 本轮不需要先重跑整条四任务链；两个新任务序列、LoRA、第二架构及大规模选样按后续证据排期。

这是合适的工程先导起点，**仍未通过原正式联合资格**，不能改称合格R0。当前四任务终点已丢失旧技能，从该终点加回放回答的是“重新学回”，因此本计划统一退回封存的双目标模型，研究“能否预防丢失”。

E007的常规FT6结果保留为历史背景：固定右格12000步后左／前均0，新右格最终12/20。严格比较使用下面同一新入口跑出的分支，不把历史FT与新协议混成完全匹配的主表。

## 3. 旧记忆先用最普通的随机规则

1. 只在旧左／前训练划分中，按固定记忆种子`20261024`，每目标均匀无放回抽256个记录，最多512条。不能用历史评估失败状态或验证轨迹挑记忆。
2. 一条记录自包含：两张128×128 RGB图（uint8）、机器人状态、真实指令、50步真实动作块、有效mask、轨迹／帧来源与必要元数据。动作块不跨轨迹，末尾补齐规则与现有数据接口一致。
3. **总预算上限64MiB（67,108,864字节）**，图像、动作、mask、来源、统计和索引全部计入。仅双RGB原始图约48MiB，实际文件大小以导出清单为准。超预算时在训练前按相同规则等量减少记录，先固定最终清单和实际字节，不看评估分数后调整。
4. 切换到右格后，ER的数据访问只限新右格训练集和这份自包含记忆；旧完整视频不再从索引免费读取。父权重／归一化用于初始化，ER不额外调用教师。
5. 此时不做难例筛选、配对伪标签或新选择器。另一条指令没有真实动作标签，就不能把原动作硬配过去。

数据划分继续继承原始配置，不能为换训练种子重新洗牌训练／验证；记忆、采样、训练和评估的随机源分开登记。

首轮建议锁定：数据划分与推理seed沿用`20261021`，训练及新样本采样seed为`20261024`，旧样本采样seed为`20261025`，均使用独立随机源。当前脚本的单一`seed`同时参与多处流程，新入口须拆开这些用途并核对原划分清单，不能直接全局替换成新seed。

## 4. 首批跑什么：两条新训练，一条历史背景

新任务仍只用右格40训练／10验证，均从同一父权重和处理器出发，重新创建优化器／调度器。

| 分支 | 每步训练内容 | 新样本损失权重 | 用途 |
|---|---|---|---|
| 历史FT6：E007，复用结果 | 6条右格 | 每条1/6 | 常规无回放损伤的历史参照 |
| **新FT4匹配对照** | 4条右格，无旧样本 | 每条1/6 | 控制新任务曝光减少及新损失系数降低 |
| **新ER** | 与FT4相同4条右格＋1条缓存左格＋1条缓存前格 | 每条1/6 | 比FT4多出真实旧样本监督 |

对应损失明确写成：

```text
FT4: L = (L_new_1 + ... + L_new_4) / 6
ER : L = (L_new_1 + ... + L_new_4 + L_old_left + L_old_front) / 6
```

FT4实际batch为4，但损失按6个位置归一化；**不能写成默认的4条平均损失**，否则新损失系数仍与ER不同。FT4是实验控制，不能替代正式论文中常规FT基线。

两条新分支各12000次更新，右格曝光均48,000条；ER另有24,000条旧样本曝光。匹配的是新样本曝光、损失系数、更新和初始化，**计算量并不相同**。报告ER额外前反向成本，不称等FLOPs比较。梯度裁剪及AdamW会让新旧梯度产生交互，不宣称更新后的“新任务贡献”仍完全相同。

实现上预先生成每步4条新样本和旧样本索引清单，FT4／ER读取同4条新样本；对新样本显式传相同flow noise／time，保持相同预处理、mask及其他随机设置。现有SmolVLA接口支持`noise`、`time`和逐样本loss，仍需在新训练入口中接线并核验。

固定设置：冻结VLM，更新现有动作专家及相关投影；联合左＋前归一化不变，lr1e-4、warmup100、BF16、chunk50、flow10、执行10步。3000／6000／9000／12000保存并重载，最终固定12000。分支之间不共享新任务优化器状态，不按最终分数选最好点或加步数。

## 5. 训练前先把执行失效单独说明白

先复用E005、E009已有轨迹，整理请求目标成功区间、首次任一目标、最终目标，以及物体／夹爪在成功后的变化。优先覆盖后格13个成功后失效，另取成功和从未成功案例作对照；不只展示最强替代视频。

这些分析与新ER训练可并行，不要求为此再续训后格。若现有记录不能区分反馈频率的影响，再开一个明确标注的开发控制：固定E009后格权重、开发初态0—9，执行10步与1步后重规划各10回合，均400步，额外最多20回合。它不进入FT／ER主表，也不据此修改某一条分支的推理设置。

主协议继续400步，保留原生“曾成功”和固定终态指标。另记录最长连续成功、成功后失效及其最终去向。成功即停止只可作为另列参照，不能把原指标替换后宣称训练方法解决问题；暂不把夹爪命令或短暂谓词当成已放稳。

## 6. 2A怎样考试、看什么

首轮终点仍用历史20—39初态，两个新分支各测左／前／右／后20次，共**160个新终点评估回合**；R0的80回合按条件核验后复用，E007 FT6仅作历史背景。后格此轮不训练，只诊断未适配指令是否退向已训练目标。

0—19继续用于开发；如需检查中途变化，预先安排6000步左／前／右各10次，每分支30，共另增60回合，不能观察分数后挑检查点。首批默认只做固定终点；训练／验证loss和保存完整性照常记录，闭环曲线另记执行量。

每个模型固定输出：

- 全20回合的请求目标曾成功、最终正确、首次／最终目标矩阵；先成功后失效单列。
- 旧左／前前测最终成功各16个状态：保住多少、首次／最终新右多少、其他格多少、未完成多少。曾成功分母另列，不能混成一个数。
- 原左／前都最终正确的13个共同初态：双指令保留多少、两条旧指令都转右格多少。
- 新右格相对R0的学习增益，以及FT4／ER的新旧折中；同时报告所有失败，不仅看新任务成功的状态。
- 旧缓存实际字节、逐目标／逐轨迹覆盖、全部新旧样本曝光、耗时、峰值显存、代码／数据／父子模型哈希。

两分支的评估状态／XML／推理种子／400步严格对应。低分不重试；运行错误保留原产物，最多重试一次。20—39已被反复查看，因此2A全部标为开发性先导，不称独立资格或未见测试结果。

## 7. 按实际结果决定下一步

| 2A观察 | 结论与动作 |
|---|---|
| ER保住旧指令且右格也学到 | 普通回放在此预算下有用；先复验，不急于发明新选择器 |
| ER旧任务好，但右格明显更差 | 保持—学习折中；不能仅凭旧任务分数宣布解决 |
| ER与FT4都比历史FT6好，ER无额外收益 | 与新曝光／损失权重减少的解释一致；历史实现和随机条件也可能影响，不能唯一归因，保留负结果 |
| ER右格学到，旧目标仍有明确新发替代 | 有残留缺口；先用合格R0及独立训练复验，再做机制 |
| ER主要剩未完成、没有明确错目标 | 优先执行／结果维持诊断，不硬套语言选择保护 |
| 新右格始终学不好 | 优先检查新任务学习配方；本轮不支持稳定新任务下的保持主张 |

把右格曾成功及最终正确均≥16/20作为描述性高成功筛查；达不到就明确报告质量限制。这个阈值不保证总体80%，也不用于回头改选终点。ER即使旧任务保住，只要新任务差，就先展示完整折中，不包装成成功。

若首轮确需改学习率、比例或预算，先根据开发诊断写下一版协议，并对所有相应对照同改；不只给某一方法额外预算。

## 8. 进入正式机制／方法前：2B补齐什么

**先导有用不等于正式起点合格。** 正式阶段重新从原始基座建立左＋前R0，仍按逐目标和同状态双指令共同终态门槛确认；旧规则不追认修改。

先检查联合训练后期前格退化及释放／结束问题，再锁一套有限的新配方。建议将“恒定lr1e-4”改为有预定衰减的单一候选配方，例如warmup100后余弦降至1e-5、最大18000步，开发候选仍6k／12k／18k；这是待验证改动，不保证能通过。首个开发逐目标及共同终态均≥16/20的候选冻结；18k仍失败则停止扩方法，回到起点学习诊断，不无限加步。

现有0—49初态都有使用历史。正式资格与最终确认另建立并锁定两组各20个合法新物理状态／XML，检查无初始成功、无训练／历史状态重复、跨指令复位一致；由环境合法复位流程或独立任务流提供，不靠换推理seed冒充新状态，不按FT／ER成绩筛状态。接口若暂不支持，就先补初态生成与审计。

冻结候选后一次资格检查左／前各20，逐目标及共同终态均≥16/20；资格失败不回头挑另一候选。同样通过后，才在另一封存20状态上确认后续适应。所有方法统一推理设置；资格／测试成绩不用于选记忆、窗口或超参。

在第二组封存20状态上，先评估冻结R0的四条指令各20次，再评估各适应模型的同80个条件。遗忘分母取这组状态中R0实际成功的回合，不能拿另一组资格分数替代。前测结果不用于更换状态或挑方法；只有真正跨模型条件相同时才复用缓存。

重跑常规FT6、匹配FT4、普通ER，先至少两个完整独立起点／训练过程看是否复现；仅从同一R0换适应seed，只是适应随机性复验。正式主结果再扩至少三个独立训练种子和另一未用于设计的任务流，不能把SCENE2里的多个格子当多种场景。

## 9. 有残留缺口后：机制与原方法候选怎么接

先在合法“书已抓稳、尚未进入任一格”的共同状态比较R0、FT、ER，要求R0确实能按左／前分别完成；完整任务结果仍保留。然后预登记候选，逐项验证：

| 待验解释 | 预测与最小检查 |
|---|---|
| 动作专家读取VLM条件的接口改变 | 同状态下替换对应读取模块／激活，目标选择有特异变化；先审计算图，不假定存在独立cross-attention层 |
| 状态信号压过目标条件 | 状态投影／相应注入变化能改变旧指令错目标，需要与不破坏操作的控制区分 |
| 动作读出或目标相关运动策略被覆盖 | 条件读取得到修复仍不够，恢复运动／读出更有效；不能把它自动归为语言通路损伤 |

保留原功能实验：同输入、同noise／time比较旧平均响应与旧指令区别的交换；自替换、错误指令、等范数随机修正、当前区别放大，以及健康背景下的反向破坏共同判断。只有一次救援先称补偿，不能确诊成因。VLM冻结不等于内部目标信息已经证实保留。

**原区别蒸馏候选保持不变：** 在合法旧状态上保留“换指令应怎样改变动作”的响应区别，同时保留事实动作回放，允许共同响应改变；保护是否合适由上述证据决定。当前只有左／前两条已学旧指令，教师约束用这两条，不把教师未掌握的右／后也当可靠监督。

**互补选样回放仍是后续候选：** 在相同字节预算中，让记忆覆盖不同条件损伤方向，另保留抓取／释放等操作覆盖。它不是已经验证的创新；规则只能用旧训练／开发证据锁定，不能看正式测试错误后挑记忆。

后续最小因素表仍为A随机ER、B随机状态＋原蒸馏、C互补选样ER、D互补选样＋原蒸馏。A/B、C/D分别共享事实回放清单，只切换蒸馏；再列真实等字节主表，教师缓存同样计费。D优于B才支持选样对原蒸馏的额外价值；完整输出KD在同状态、同教师权限、同预算下作为必要保护对象对照。普通ER若已足够，就收窄方法主张。

## 10. 双3090的首批预算与交付

| 工作 | 资源和执行量 | 预估／完成标准 |
|---|---|---|
| 记忆导出与先导核验 | CPU为主；旧数据导出一次 | 512条以内／64MiB以内，自包含、无旧视频回读、mask及归一化正确 |
| FT4匹配对照 | 单3090，12000步 | 与ER共享4条新样本及随机输入；固定终点 |
| 普通ER | 另一3090，12000步 | 4新＋1旧左＋1旧前，固定终点 |
| 终点评估 | 两卡分担两个模型的四指令 | 160新回合，R0已有80回合核对后复用 |
| 可选中途／执行控制 | 单独登记 | 中途60回合、重规划控制20回合，均非首批必需 |

上一阶段batch6训练12000步约49—53分钟。先导两条训练粗估合计2—3个GPU小时，加两模型终点评估约0.5个GPU小时；缓存读取、保存及并行I/O会改变吞吐。**工程入口就绪后，双卡首批目标约1.5—2.5小时墙钟时间**，不是已排定的完成承诺。实现／缓存验收另预留半天至一天；2B重建R0和复验另计，不混入首批时长。

两人分工：A负责记忆导出、匹配采样／损失和训练；B负责既有后格失效诊断、四目标配对评估及结果审核。

两张3090各运行一条完整训练分支，不需要把两卡组合成同一模型的DDP；终点评估再按GPU空闲情况分配，避免评估影响另一分支的训练验收。

当前可复用模型加载、时序转换、固定步训练、保存重载、四目标评估和结果核验。**尚需实现**自包含旧记忆导出／读取、FT4分母控制、ER混合与新noise/time匹配、曝光清单、两分支入口及统一报告。本文不是已经可运行的一键脚本，不应直接拿旧四任务入口代替。

首批验收只交四样：①缓存／预算／权限清单；②两分支新旧学习及配对目标转移表；③成功后失效与普通未完成分解；④按第7节作出的推进决定。只有真实完成的实验才追加E010及后续记录，本计划不预填结果。
