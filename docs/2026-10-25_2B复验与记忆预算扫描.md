# 2B：适应种子复验、ER记忆预算扫描与参数替换开环筛查

日期：2026-10-25。父模型、配对初态和评估协议同2A（[2A结果与论文叙事](2026-10-24_2A结果与论文叙事.md)）。全部模型都跑满固定的12000步，每个模型在四条指令下各评估20回合；6个2B运行一次完成，无报错。证据见[`docs/results/2026-10-25/stage2b_results/`](results/2026-10-25/stage2b_results/)。

## 1. 设置

- **种子复验**：s2、s3两个新适应种子，同时更换记忆抽样、新样本流和旧样本流（20261124/25、20261224/25），各跑一次FT4和ER256。s1即2A。
- **预算扫描**：ER每目标64/16/4/1帧，与ER256使用同一新样本流（s1），记忆从256帧中按固定顺序截取前缀，嵌套关系为1⊂4⊂16⊂64⊂256。记忆大小依次为12.8 MB、3.2 MB、0.8 MB、0.2 MB。

## 2. 指标：书本被送往哪里

在首次到达目标与曾成功之外，用逐步轨迹给“从未满足任何格谓词”的回合补充去向。对抬起过书的回合，取搬运过程中书本离哪个格中心最近（水平面）。这样每个旧指令回合可分为四类：

- 成功；
- 送往正确格附近但没放进去；
- 送往右格（首次到右，或最近的是右格）；
- 其他（没抓起来，或去了别的格）。

## 4. 可以写的结论（单父模型、复用初态20—39、探索性）

1. **目标替代在三个适应种子上稳定复现。** FT4下左、前两条旧指令40回合中，有36–37回合把书送往新的右格（约90%），没有一次完成旧目标。
2. **普通ER在三个种子上都完全消除了替代。** 送往右格0/40；左指令成功18–20/20。前指令成功8–16/20，波动较大，失败几乎都是送到前格附近没放进去。
3. **选择与执行的代价分离。**
   - 每目标16帧（3.2 MB，预算的1/20）时，旧指令送往右格仍为0，“目标选对”（成功加正确格附近）在左、前合计为36/40。
   - 每目标4帧时，选择大体保住（左17/20成功，前9/20去前格附近、4/20去右），但前格执行完全失败（0/20成功）。
   - 每目标1帧时，替代重新出现：左18/20去右，前13/20去右。

   也就是说，保住“去哪个格”只需要每目标几帧，而保住精细放置需要多得多的记忆，而且随种子波动。

4. **新任务的代价。** 右格曾成功从ER256的17（s1）随预算减少降到10（1帧）。这是单种子观察，尚不能确定是预算的作用还是噪声。

## 5. 参数替换开环筛查（因果定位的预筛，未做闭环）

在固定画面、状态和噪声下，构造“FT4终点换回父模型某组参数”（恢复）与“父模型换入FT4某组参数”（破坏）的混合模型，比较左/前指令下的输出最接近哪个目标的参考输出（每条指令400帧·噪声）。

| 换入父模型的FT4参数组 | 左→右 /400 | 前→右 /400 |
|---|---:|---:|
| 读取VLM的k/v投影（奇数层，160万参数） | 0 | 0 |
| 全部query / 注意力输出 / 自注意力k/v | 1 / 2 / 0 | 0 / 1 / 0 |
| 全部MLP | 16 | 27 |
| 状态投影 / 动作输入输出 | 1 / 4 | 0 / 2 |
| 前8层整体 | 43 | 36 |
| **后8层整体** | **254** | **231** |
| 后8层注意力 / 后8层MLP | 92 / 0 | 37 / 4 |
| 8–11层 / 12–15层 | 8 / 61 | 16 / 12 |

恢复方向：只换回读取投影，左→右仍为363/400，几乎没有恢复；换回后8层，前指令有187/400帧恢复到最接近前格（FT4为3）。归一化层在微调中完全没有改变，作为空操作对照，输出与原模型逐位相同。

开环解读（**已被闭环验证部分推翻，见[2C参数替换闭环验证](2026-10-25_2C参数替换闭环验证.md)**）：开环下替代看起来集中在动作专家后8层。闭环中，只确认了“读取VLM特征的投影不是替代所在”这一点；“后8层单独就能引出替代”没有成立。
