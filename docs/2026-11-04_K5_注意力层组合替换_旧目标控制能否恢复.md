# K5：把注意力层“组合换回旧模型”，旧目标控制能恢复吗？

日期：2026-11-04。运行：服务器 `.server/k5_attention_combination_20261104_01`（预登记在跑之前写定）。不训练；只在推理时把 FT4 动作专家选定层的**注意力模块**临时换成 R0 的，跑完 400 步闭环，看旧指令（左／前）能不能重新按指令分流。

## 0. 一句话

**换任何组合都不行，包括把 16 层注意力全部换成旧模型的。** 换全部层确实改变了行为——从“两条指令都去右格”变成“左指令去前格、前指令多半不动”——但**没有恢复“给左去左、给前去前”的条件控制**；只换浅／中／深任意一组则完全无效。这说明“指令→目标”的映射不是靠换注意力模块能救回来的，而注意力层确实承载了一部分“默认往哪走”。

## 1. 为什么做这个

- 单层 CA 换旧消息已做过：128 条正确来源条件，首次目标 0/128。
- 整段参数互换（前半/后半专家、读取 K/V 投影）也失败（2C）。
- 组员指出：动作专家偶数层是自注意力（SA），**推理时 SA 层也直接读前缀 K/V**，所以只换 CA 会漏掉一条通路。
- 于是做“组合”：浅／中／深／全部 CA，以及含 SA 的整层段。

## 2. 设计

**替换方式**：把 FT4 第 i 层的 `input_layernorm + self_attn`（即整个注意力块）换成 R0 同一层的模块。这样 R0 的注意力是**在 FT4 当前的隐状态上现算的**（耦合式，V2），不是贴旧模型的存量消息。残差、MLP、动作输出投影仍是 FT4 的。

**状态**：R0 用指令 A 走 40 步得到的同一状态，初态 4／6／8，共 3 个。三个都是合格的“差距状态”（R0 双向分流 D=1，FT4 都去右格 D=0）。

**条件**（每个状态 × 左右两条指令）：

| 条件 | 换哪些层 |
|---|---|
| NAT-FT4 / NAT-R0 | 不换 |
| SELF-ALL | 换成 FT4 自己（恒等门禁） |
| CA-shallow / mid / deep | 1,3,5 / 7,9,11 / 13,15 |
| CA-ALL | 全部 8 个跨注意力层 |
| CA-mismatch | 8 个 CA，但层号与来源**错配**（1↔15、3↔13…），同样改动量、对应关系错误 |
| SEG-0-5 / 6-10 / 11-15 | 含 SA 的整层段 |
| SEG-ALL | 全部 16 层 |

**门禁**：SELF-ALL 的动作序列必须与 NAT-FT4 **逐位相同**（三个状态全部通过）。

## 3. 结果

D = 同一状态上，指令 A 首次去左格 **且** 指令 B 首次去前格。

| 条件 | 初态4（A/B） | 初态6（A/B） | 初态8（A/B） | D |
|---|---|---|---|---|
| NAT-FT4 | 右/右 | 右/右 | 右/右 | 0/3 |
| NAT-R0 | 左/前 | 左/前 | 左/前 | **3/3** |
| SELF-ALL | 右/右 | 右/右 | 右/右 | 0/3（逐位一致） |
| CA-shallow | 右/右 | 右/— | 右/右 | 0/3 |
| CA-mid | 右/右 | 右/右 | 右/右 | 0/3 |
| CA-deep | 右/右 | 右/右 | 右/右 | 0/3 |
| **CA-ALL** | **前/—** | **前/—** | **前/右** | **0/3** |
| CA-mismatch | —/— | —/— | —/— | 0/3（崩溃） |
| SEG-0-5 | 右/右 | —/— | 右/右 | 0/3 |
| SEG-6-10 | 右/右 | 右/右 | 右/右 | 0/3 |
| SEG-11-15 | 右/右 | 右/右 | 右/右 | 0/3 |
| **SEG-ALL** | **前/前** | **前/前** | **前/—** | **0/3** |

补充对照（只换投影、保留接收方 LayerNorm）：CA-ALL-proj 与 SEG-ALL-proj 的结果与整块替换**完全同型**（前/—、前/前），说明“换 LayerNorm 导致分布偏移”不是这个阴性结果的原因。

## 4. 怎么读

1. **局部无效、全换才有效果**：浅／中／深任意一组单独换，行为一点没变——信息在这几层之间高度冗余，单组会被其它层补回来。只有整栈 8 个 CA（或全部 16 层）一起换，行为才变。
2. **变的方向不是“恢复控制”**：CA-ALL 让左指令去前格（一个旧目标），前指令多半不再搬运；SEG-ALL 让两条都去前格。这是“换回了旧模型的一部分默认轨迹”，**不是**“按指令选目标”。
3. **错配对照直接崩掉**（三个状态都不再进任何格子），说明这次替换不是无关痛痒的扰动，对应关系是重要的。
4. **结论**：注意力模块本身不承载“指令→目标”的可替换映射；它承载的是“默认往哪走”的那部分轨迹。条件选择要么在 MLP／残差／输出投影里，要么是整栈协同产生的、换模块无法复现的性质。

这与三条旧结果一致：单层 CA 0/128、整段参数互换失败（2C）、输出层“共同响应主导、区别项救不回”（K1/K2）。

## 5. 边界（必须一起说）

- **混合模型是分布外输入**：R0 的注意力接在 FT4 的残差流上，即使只换投影也一样。阴性结果只能说明“这样换救不回”，不能证明“信息不在注意力里”。
- 只换注意力块（LN+self_attn），没换 MLP、残差、动作输出投影；也没做“换 MLP”的对照。
- 单场景族（SCENE2）、3 个状态、每个条件一条噪声流；不是独立重复。
- 只测了“首次目标”，终态成功整体偏低，未单独分析。

## 6. 下一步

1. **补 MLP／输出投影的对照**：同样按层段换 MLP，和注意力换的结果拼起来，才能说“哪一块承载默认”。
2. **错配梯度**：把 CA-ALL 的层对应关系从“完全错配”到“正确”，看行为何时从崩溃回到‘前格’，定位耦合强度。
3. **数据侧**（组员建议的第一优先）：用新任务示范的不同片段训练，看“默认”被哪一段改写——这条比继续换模块更能回答训练致因。
4. 换第二个模型族（Goal）复核：Goal 的替代与文字无关，预计注意力替换的形态不同。
