# K7：整层替换与分层组合——只有“全部 16 层”能改变默认，且代价是新任务能力

日期：2026-11-04。运行：`.server/k7_whole_layer_20261104_01`。全程由 FT4 控制（第 0 步到 400 步，无 R0 前段）；10 个开发初态 × 左/前两条旧指令；**替换的是整层**（注意力 + MLP + 两个 LayerNorm），不是只换注意力。

## 0. 一句话

- **分层/分组合替换全部无效**：第 0–3、4–7、8–11、12–15 层任一组，或累积 0–7、0–11，旧指令仍然两条都去右格（D 0/10），行为和原生 FT4 一样。
- **只有把 16 层全部换掉**，行为才变：给“左”10/10 去左格并成功，和 R0 一样；但给“前”只剩 3/10 去前格、7/10 直接不搬。
- **代价**：全换之后，用新指令“右格”只有 0/10 去右格——模型已经不是 FT4 了。

所以“默认目标”不是存在某一层段里，而是**整栈 + 共享输入/输出投影一起耦合出来的**；换一半（甚至换 12 层）都会被剩下的部分拉回“右格”。

## 1. 做法

| 项目 | 设置 |
|---|---|
| 接收方 | FT4（学完右格、无旧回放） |
| 供体 | R0（左＋前父模型） |
| 替换单元 | **整层**：`input_layernorm + self_attn + post_attention_layernorm + mlp` |
| 条件 | 全部 16 层；四分段 0–3／4–7／8–11／12–15；累积 0–7、0–11；原生 FT4、原生 R0 |
| 初态 | 开发初态 0–9，共 10 个（比之前 3 个多） |
| 指令 | A=左格、B=前格（每条各 400 步，全程同一模型控制） |
| 胜任力对照 | 原生 FT4 与“全换”各用新指令 N=右格跑 10 条 |
| 总回合 | 200（9 条件×2 指令×10 + 2 条件×10 新指令） |

判据：首次目标、D（给左去左且给前去前）、请求目标的原生成功。

## 3. 怎么读

1. **分层替换是“无效”而不是“部分有效”**：四段任意一段换掉，A、B 仍然都去右格，和原生 FT4 几乎一样；累积到 12 层（CUM-0-11）也只是把 A 推到“前格”，B 直接不搬，D 仍然是 0。
2. **全换才能改默认**：ALL-16 下 A 稳定去左格并成功（10/10），和 R0 一致——说明“默认目的地”确实可以由整栈的旧计算改写。
3. **全换也不是干净的 R0**：B（前格）只剩 3/10 能到、7/10 完全不搬；而 R0 自己是 9/10。剩下的差异只能来自**没换的部分**——输入/状态嵌入、动作输出投影、最终 norm。
4. **全换把新任务能力打没了**：N→右格 0/10。所以 ALL-16 是一个“接近旧模型、但旧任务只恢复一半、新任务不会”的嵌合体，不能当成“修复”。

## 4. 和 K5 的关系

- K5 只换**注意力**（LN+self_attn）：全换 8 个 CA 或 16 层注意力，默认从右格挪到前格，但左/前分流一次都没回来。
- K7 换**整层**（再加 MLP 和 post-LN）：全换 16 层，左格程序回来了（A→left 10/10），前格程序坏掉。
- 合起来看：**注意力决定“大致往哪走”，MLP/其余部分决定“这条程序能不能完整执行”**；两者是共同训练出来的，单独换哪一半都不够，全换又会因为剩余的共享投影而不匹配。

## 5. 边界

- 混合模型分布外：R0 的层接在 FT4 的残差流和输出投影上，行为不能等同于“R0 复活”。
- 只换 16 层 expert layer，没换嵌入、动作输出投影、最终 norm；这正好是下一步要补的对照。
- 单场景族（SCENE2）、10 个开发初态、每个条件一条噪声流；不是独立重复，10 个初态也仍是同一批场景配置。
- 判据用“首次目标 + D”，终态成功作辅助。

## 6. 下一步

1. **补输出投影/嵌入的替换**：把 `action_out_proj`、状态/动作嵌入也换成 R0，看 ALL-16 能不能从 3/10 变成 9/10——这能确认“前格程序”是不是卡在输出投影上。
2. **累积细扫**：0–13、0–14、0–15 逐层加，找“左格程序”从哪一层开始回来（现在 12 层还不够，16 层才行）。
3. **胜任力门禁**：以后任何“修复”都必须同时报新任务成功率；ALL-16 的 0/10 说明它不能算方法。
4. 按组员建议转**数据侧**：用新任务示范的不同片段训练，找“默认”被哪一段写进去——比继续换模块更接近训练致因。
