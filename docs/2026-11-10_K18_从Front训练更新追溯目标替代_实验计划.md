# K18：Front 训练怎样改写旧动作响应——训练致因实验计划

日期：2026-11-10。状态：已核对训练记录与历史代码，完成分阶段方案；尚未执行本计划的新训练、梯度实验或评估。阶段标签和候选干预须在开发数据上核验后锁定，再做确认。

## 1. 下一步要补上的因果链

K14～K17 已经回答了一部分功能机制：续训模型残留的旧指令差别，配上哪些共同动作响应后能重新控制机器人。它们尚未识别让这些响应发生变化的具体训练来源。

下一步以这条链为主线：

```text
Front 示范中某类监督
    ↓
产生什么梯度，经过裁剪和 AdamW 后真正怎样改动参数
    ↓
为什么同一输入上的旧 μ_H／μ_R／μ_Z 和指令区别 d 改变
    ↓
不加推理补丁的模型，何时开始选错目标或到位后失去成功状态
```

研究对象先固定为同一条 R1（左＋右）→Front 线路。核心行为结果必须来自训练后模型的原生推理。推理阶段的 μ/d 替换只保留为已有机制证据，不作为本计划主要验证手段。

## 3. 目前可以提出的解释，只能先当假说

为了学 Front，仍可训练的共享动作系统改变了参数。Left、Right 虽未参与这批监督，查询它们时仍使用同一套参数，所以输出也可能改变。冻结视觉语言骨干，并不等于冻结“指令＋状态→动作”的映射。

但这还没有回答：为什么更新会削弱旧条件区别、改变共同动作安排，而不是形成兼容新旧任务的解。

要区分的候选解释至少包括：

1. **特定监督来源的方向性干扰。** 某阶段／某通道的 Front 监督，特别容易改动对旧任务敏感的参数方向。
2. **分散的共享更新。** 多类监督都在累积推动变化，并不存在单一的“坏旋转监督”。
3. **优化历史与量级作用。** 动量、二阶缩放、裁剪和热身，可能放大或延续某类方向；不能只看当前梯度。
4. **测量分布或闭环反馈影响。** 固定旧状态上的直接变化，与模型自己走到不同状态后暴露的失败，可能不完全相同。

K17 中旧旋转响应有效，不能推出 Front 的旋转损失就是损伤来源。Front 水平监督也可能经共享参数改变旧旋转输出。**被救回的功能位置与写入损伤的监督来源，必须分开检验。**

## 4. K18-A：先找变化从何时开始

### 4.1 重建一条可核验基线

从原 R1 权重和处理器开始，用原 Front 数据划分、seed、batch、AdamW 初始化、热身和损失分母重建到 6000 步。现有 12000 检查点作为终点参照。

补记录：`0、10、30、100、300、1000、3000、6000` 步。0 步是父模型加全新优化器状态，不是恢复 R1 的训练动量。

每个点保存可训练权重、优化器／调度器、全部随机状态和数据位置；模型全量存储可较稀疏，冻结部分以父模型和哈希引用，避免大量重复保存。增量模型必须通过重建一致性验证。

先校验前段 batch 索引、学习率、训练损失，以及 6000 步模型读数与已有模型的对应关系。哈希完全一致为优选；若无法达到，须定位随机／代码差异，并把它标成新的受控复现基线，不能称为原训练轨迹的精确回放。

### 4.2 输入固定，避免把路线变化误判为参数变化

建立封存探针库，覆盖：

- K14 的共同抓持快照，用于连接已有机制结果；
- 旧 Left／Right 示范中的抓取、搬运、放置状态；
- Front 示范状态和独立验证示范，用于检查新任务拟合。

固定每项的图像、机器人状态、动作草稿 x、去噪时间 t 和噪声。动作草稿从父模型参考轨迹或固定的示范动作加噪构建并保存。每个 x 都同时查询 Left 和 Right；不能每换检查点就换成它自己的草稿路径再直接比较。

探针应覆盖多个去噪时刻。推理探针和训练实际加噪输入分开记录，检查结论是否只存在于某类输入。旧区别接近退化的输入须按父模型上预先确定的规则单列，不能事后因结果不好而删掉。

### 4.3 同时跟踪几种变化

记父模型区别为 d₀，检查点区别为 dₛ：

```text
旧方向上的有效增益 = <dₛ,d₀> / ||d₀||²
区别总强度         = ||dₛ|| / ||d₀||
另记方向余弦与非共线变化
```

同时记录 μ 的水平、旋转、高度部分相对父模型的漂移、P 的间接变化，以及 Front 独立验证误差。增益和范数都是动作响应读数，不是语言能力百分比。

d 的主读数在有效 7 维上计算，动作序列前 10 个位置与全 50 个位置分别报告，P 单列，不把填充维度混进有效动作区别的分母。

原生闭环评估报告 Left／Right／Front 各至少 20 个状态的首次目标、曾成功、终态和未达区域，Left／Right 分开；旧任务在固定共同抓持状态下接手，新任务另报告从复位开始的能力。不要让早期模型自己执行 Front 前缀，导致不同检查点从不同物理状态比较旧分流。

为控制成本，固定输入读数用全部采样点；完整闭环先评父模型、1000、3000、6000，再依预登记规则定位变化区间。更密集的闭环切点只能在开发集选择，不能把挑出的最坏时刻当独立确认。

**本阶段回答时间关系，不能单凭先后顺序认定原因。** 如果 d 先衰减、μ 后漂移，和反过来相比，后续要追的更新区间不同。

## 5. K18-B：查哪类监督通过真实优化器步写入变化

### 5.1 在同一个训练批次上拆损失来源

先按四类有效输出拆：H（水平）、Z（高度）、R（三轴旋转）、G（夹爪）。再按示范中的抓取／提起、持书搬运、下降／放置阶段细分。阶段标签来自 Front 原始示范事件，须人工抽查并锁定；难以分类的片段单列 unknown，不能直接丢弃。

每个未来动作位置都按它对应的原示范时刻标阶段。当前 chunk 可能横跨多个阶段，不能根据当前观察的阶段给整段 50 个动作贴同一标签。必须处理 offset=1、尾部 action_is_pad 和示范边界。

保持完全相同的模型输入、噪声、时间和预测，只给未归约的损失元素分类。保留原来每个样本的有效时间×7 分母及 batch 平均权重，使：

```text
完整损失 = 所有阶段×通道分量损失之和
裁剪前完整梯度 ≈ 各分量梯度之和（在校验过的浮点容差内）
```

不要给每一小块分别取均值后相加，那会改变原训练中三维旋转、二维水平与单维夹爪的相对权重。输出源可被拆开，不代表其梯度只更新同名模块。

### 5.2 每次分叉恢复同一权重与完整优化状态

选最早变化区间前后以及一个后期点为锚点；每点使用多批预先固定、覆盖不同示范和阶段的 Front 数据，不能凭一个 batch 下结论。

在同一锚点上建立以下局部分叉：

| 分叉 | 做什么 | 用途 |
|---|---|---|
| Full | 原始完整 Front 损失 | 真实更新参照 |
| Only-C | 只用监督分量 C | 检查该源是否局部足以引起变化 |
| Without-C | 完整损失扣除 C | 检查当前监督的边际贡献 |
| Zero-gradient | 显式给参数零梯度，但推进同一 AdamW | 测历史动量与衰减仍会带来什么变化 |
| No-step | 权重完全不动 | 数值／测量底噪参照 |

所有分叉恢复同一 θ、AdamW 一二阶状态、调度器和随机状态。Zero-gradient 不能用 grad=None 代替，因为优化器可能跳过这些参数。

记录梯度、裁剪系数、实际学习率、参数前后差值 Δθ，以及 μ/d 读数的精确变化。**必须实际执行优化器步骤，不能用“梯度方向很像”代替参数更新证据。** AdamW 的分量更新通常不能相加；Only-C 还带着相同历史动量，需与零梯度参照一起解释。

若一步变化低于重复测量精度，按事先规则改用 10 或 30 步短窗口；不要在探针上任意放大参数改动直到出现显著结果。分量之和的一致性检查在裁剪前进行，裁剪和 AdamW 后另外记录真实差异。

输出一张“监督来源→旧响应变化”表：每行一个阶段／通道源，每列分别是旧方向增益、μ_H、μ_R、μ_Z 等的变化。**旋转损失是不是主因，由这张表决定，不由 K17 的补丁位置决定。**

### 5.3 对局部解释做方向性校验

在小更新下，两条旧指令的响应变化近似为它们对参数的敏感性乘实际 Δθ：

```text
Δμ ≈ ½(J左＋J右) Δθ
Δd ≈ ½(J左－J右) Δθ
```

通俗地说，同一个 Front 更新，可能同时推动两句的共同部分，也可能压低它们的差别。可用方向导数及小步有限差分检查近似是否成立；当实际非线性变化很大时，以真实前后读数为准。

这一步才开始回答“为什么旧指令不在训练批次中，它们的动作也会改变”。具体哪个监督产生怎样的 Δθ、作用在哪个敏感方向，需要测出来。

## 6. K18-C：把监督源与责任参数更新连接起来

对锚点短训练区间的真实 Δθ，按互不重叠的五组可训练参数划分：

1. 状态投影；
2. 动作草稿／时间输入投影；
3. 动作专家注意力；
4. 动作专家 MLP 和归一化；
5. 动作输出投影。

确认五组覆盖全部 155 个可训练张量，没有重复或遗漏。来源 C 可以同时影响多组，不能把“旋转损失”直接等同于“旋转输出头更新”。

从同一锚点权重测试：只施加某组真实 Δθ、从完整 Δθ 中去掉该组，以及在同样参数位置施加匹配逐张量范数的随机符号方向。比较固定输入响应和未加补丁的原生行为。

该实验干预的是**训练产生的参数变化**，不替换推理输出。单组更新和缺组更新用于检验局部充分性／条件必要性；参数组之间也可能存在配合，不要求一定找到一个孤立“坏层”。随机方向对照用于排除仅仅改动量大的解释。

把去掉的更新加回后完全重建 Full，只能作为工程一致性检查，不能当作独立的机制证明。更重要的是：选定更新在独立批次／续训随机流中是否仍引起同类变化，以及去掉它是否有选择地保住旧响应。

## 7. K18-D：用短程训练检验是否真的导致目标替代

在局部实验确定候选 C 后，锁定四条训练分支：

| 分支 | 训练处理 | 要排除的解释 |
|---|---|---|
| T1 Full | 正常 Front 训练 | 复现损伤与新学习 |
| T2 Remove-C | 去掉候选监督，保留原分母 | 检查来源作用 |
| T3 Random-mask | 删除匹配数量／权重、有效时间范围的随机监督 | 排除只是少学了一些 |
| T4 Norm-matched Full | 完整监督，实际参数步长范数匹配 T2 | 排除只是整体更新变小 |

随机遮蔽须按样本和动作时间区间匹配；阶段特异性另用同通道的随机时间位置控制。范数控制匹配实际 Δθ，不只把原始梯度乘一个数；AdamW 会让两者不等价。若调整参数步长，明确标成范数控制算法并记录，不把它写成未修改的原训练。

**主要源头检验从 R1＋新优化器的第 0 步开始屏蔽 C。** 如果从晚期锚点开始删除 C，已有动量仍可能继续损伤，它只能回答“能否停止继续恶化”，不足以排除 C 曾经造成初始损伤。

先按 K18-A 的开发时间线锁定 1000 步或 3000 步预算；同一比较中四组步数和 Front 样本曝光一致。每个续训随机流内，使用相同 batch 索引、噪声、去噪时间和随机处理；各分支优化器只在起点相同，后续随干预正常演化。

最终同时报告：

- 不加任何推理补丁的 Left／Right 首次、曾成功、终态，各至少 20 次；
- 新 Front 的相同评估，以及按阶段／通道拆分的独立示范验证误差；
- μ/d 和实际更新读数；
- 每个状态获得或丢失的回合，目标替代、未达目标、到达后失败分别列出。

若 T2 保住旧任务只是因为 Front 根本没有学会，只能得到学习冲突或代价证据，不能声称找到了可选择分离的损伤源。除等步数比较外，须在预定检查点上比较相近 Front 学习质量；无法匹配时如实报告，不事后挑一个最好点。

## 8. 怎样判断不同结果

| 观察结果 | 能支持的解释 | 还不能声称什么 |
|---|---|---|
| 某源的真实更新反复造成特定 μ/d 改变，删除它比随机／范数控制更能保旧，Front 学习相近 | 源特异的训练干扰链得到加强 | 不是所有任务普遍唯一原因 |
| 水平或高度监督主要改变旧旋转响应 | 监督经共享参数跨通道影响旧控制 | 不能把补丁坐标当成责任监督 |
| 零梯度分叉后期仍沿损伤方向移动，当前源删除效果小 | 历史优化状态需要解释 | 不表示该源历史上无关 |
| 多个源贡献分散，只有整体步长控制有效 | 可能是累积共享更新／量级问题 | 不能硬选一个坏阶段或坏层 |
| 固定旧输入直接读数变化小，原生闭环已失败 | 需追分布外状态与闭环放大 | 不能只用已有标量读数解释全部行为 |
| 读数得到保护，原生旧行为仍不恢复 | 当前特征不足以闭合行为链 | 不能说机制已证实 |
| 删除源同时严重损害 Front | 存在学习代价，源可能是任务必需部分 | 不能把停止新学习包装成选择性机制发现 |

最强的可支持主张应是：**某类 Front 监督通过可识别的实际参数更新，改变旧指令的共同控制响应或有效条件增益；在控制更新量和新任务学习后，这种改变能解释未加补丁的旧任务失效。** 若证据只到局部更新或时间相关，结论就停在对应层级。

## 9. 确认、成本与执行顺序

先执行 A＋B，不直接开启大量 12000 步训练。先回答何时变化、哪些源值得追，再决定 C/D 的候选。

- 原 Front 12000 步历史耗时约 53.4 分钟；6000 步可用约一半纯训练量作为粗略预算，但密集存点和探针会增加开销。
- 四分支×1000 步×三个随机流，共 12000 步训练量；若预算锁为 3000 步则为三倍。这里是总训练量，不能当作两张 GPU 的实际墙钟时间；复核、评估和模型保存另计。
- 确认使用三个独立 Front 续训随机流；共同父模型不等于三个独立训练出的父模型。候选在开发流中选择后锁定。
- 20–39 已是开发状态。40–49 只有十个编号，还须核验是否被其他工作使用；要维持每指令至少 20 个独立确认状态，需补登记的新初态，不能把十个重复两次当二十个独立状态。
- 新状态先按物理抓持资格锁定，报告父模型上限；不按新分支是否成功挑样本。示范验证按 demo 划分，避免同一轨迹帧混入开发与确认。
- 最后在 R0→Right 线路只复验最有区分力的源和控制，不把既有 R0 时间线与 R1 拼成同一训练过程。
