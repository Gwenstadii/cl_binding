# Back问题更正：示范终点、LIBERO成功事件与F4-B24模型

2026-11-25。按研究者最新要求，主成功标准改为**请求目标的原生LIBERO判据首次满足即成功，并结束该回合**。本轮只重评分已有轨迹、修订总结并封装已有权重，没有训练或新增仿真回合。此前训练均保持停止。

## 1. 更正问题定位

现有排查没有发现足以解释该结果的训练／模型实现错误。主要问题应改写为：**训练示范的任务终点与此前额外施加的释放、持续保持门禁不一致。** Back在原生任务中已经能取得很高成功率；之前不能用第400步或额外稳定门禁不通过，直接写成“Back没有学会”。

研究者对示范结尾的检查指出，Back通常在仍夹着书时结束，没有完整演示旧门禁要求的后续松手、撤手和长时间保持过程。原HDF5训练动作的独立统计也显示：40条Back示范中39条末帧仍输出正夹紧指令，对齐后长度116–232帧。Front也有40/40条末帧夹紧，因此不是Back独有的坏标签；区别还在放置姿态和支撑条件。

结合研究者此次示范检查及已有回放，Back需要把书竖着插进后部竖槽；Left／Right／Front的书主要平放或斜躺着获得支撑。对竖立的书，尚未放稳时松手，或成功后手臂继续动作，更容易使书倾倒并离开目标；平放／斜躺对这些扰动通常更宽容。这个差异解释了为什么同样的夹持示范终点，在附加长时评估下可能出现不同退化。它不意味着单凭末帧指令就证明整条轨迹从未出现过张爪动作，也不是一次独立几何干预的定量因果结论。

旧门禁包括第400步有效、末50步至少45步有效、末10步没有双指同时接触，实际引入了原生任务之外的持续控制／近似释放要求。其中“无双指同时接触”仍允许单指接触，并不严格等于完全松手；但无论如何，它都不应作为LIBERO任务是否学会的默认门槛。

## 2. 新主评估协议：K25-native-event-v1

[LIBERO官方评估实现](https://github.com/Lifelong-Robot-Learning/LIBERO/blob/master/libero/lifelong/metric.py#L120-L144)会锁存每个环境曾出现的成功`done`，不会因后续状态失效扣回成功；向量批次在全部环境成功后可提前结束。单回合首次原生成功即停止，与这一成功计分口径一致。

本项目规则为：

1. 保持既有复位、指令、噪声和最多400个动作步；400是本项目超时上限，不宣称与官方所有benchmark参数完全相同。
2. 每执行一个物理动作，检查**当前请求目标的原生BDDL谓词**。Back回合检查Back，不因Front区域经过或其他任务成功而结束。
3. 首次满足即记成功，记录成功步数并结束；10步动作块内若第81步成功，就停在81步，不能继续执行到90步。
4. 未成功且达到400步，记失败。每组全部20个初态保留在分母中，不丢弃失败。
5. 不再要求第400步仍有效、45/50步保持或手指接触条件。原几何首达、固定400步终态和释放稳定性作为独立辅助诊断，不混称LIBERO成功。

已有完整400步轨迹可以精确重评分：新成功率等于其中请求目标原生谓词的`ever`。停止发生在首次成功之后，不改变到首次成功为止的已执行前缀，因此不需要再跑同样回合。旧400步轨迹继续保留，不能伪称原实验当时已经提前结束。

新公共组件是[scripts/k26/native_event_protocol.py](../scripts/k26/native_event_protocol.py)，提供逐动作终止及离线重评分。归档脚本保持原版以复现旧结果；**后续实验必须接入新组件，不能仅换模型名称便沿用旧的跑满400步门禁。** 在共用场景、评估多条指令时，通用环境返回的`done`可能绑定原场景任务，应显式查询当前请求目标，不能误用默认Front的`done`。

6项纯逻辑检查已通过，覆盖块内81步立即结束、成功不因后续失效撤销、其他目标不提前终止当前任务、失败超时、部分回合不计为完整试次，以及禁止结束后继续执行。

新成功事件与旧400步终态也会改变部分方法解释。例如完整残差1–400的Left事件成功为20/20，不能用旧终态9/20直接称其Left原生成功率更差；但两个完整残差窗口的Back仍是0/20，这一损失在新口径下依然存在。原始数字不删除，按不同指标分开解释。

## 5. 相关结论的更正范围

此前B0首次Back探针同样不能继续写成“Back作为首任务也学不会”：旧B0已有16–17/20曾满足，新B0-Back-Hist的6000步为20/20、12000步17/20、18000步18/20。它们未通过的是旧的附加终态／保持要求，而非本次采用的原生事件标准。它们没有三旧任务训练基础，因此不选作本轮后续遗忘修复的F模型。

当前主问题应表述为：**原生目标成功与示范之外的释放／长时保持能力是两种评价目标；竖直Back放置会放大两者差异。** 原生成功作为论文任务主指标；若继续研究释放与保持，应明确列为额外任务／辅助诊断，并提供对应监督或单独讨论，不能再用这一附加门禁否认原生任务已成功。
