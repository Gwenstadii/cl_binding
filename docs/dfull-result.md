## 1. 本文的d-full究竟指什么

固定旧候选集合O。在同一当前观察、动作草稿x及去噪时刻t，分别计算父模型P和续训模型F的旧句响应均值：

```text
μP = mean[vP(g), g∈O]
μF = mean[vF(g), g∈O]
rF(q) = vF(q) − μF
完整残差：vfull(q) = μP + α rF(q)
parallel：vpar(q) = μP + α BP,32 · pinv(BP,7) · rF(q)7
```

两旧句时rF(A)=dF、rF(B)=−dF，因而是“旧μ＋整体新d”；多旧句时用实际指令相对旧参考均值的完整残差表达。这里保留的是F自己的完整区别，不是将父模型完整d直接替换进来。真实q由F处理，P在修复中只提供固定旧参考的均值；完整残差不需要父区别轴。

公式作用于完整50×32去噪响应，再积分、执行前7维、反归一化和裁剪。因此四指令full与parallel的差别不只限于执行7维；被移除的32维响应不能简单称为32维欧氏正交分量。本文不把额外V修正、仅部分动作通道换μ、回滚模型d互换等另一类操作混作纯d-full。

### 2.1 K15：LR→Front-12000，抓稳后接手60步
