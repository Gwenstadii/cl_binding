## 2. 我们要验证什么

最小设置是LIBERO-90的STUDY_SCENE2：同一场景、同一种物体“书”、同一种操作“放入收纳盒”，指令只改变目标格子。

| 角色 | 任务 | 本轮用途 |
|---|---|---|
| 旧任务 | front / left / right | 先联合训练建立R0 |
| 新任务N1 | back | 等R0合格后才用于持续学习训练 |

核心问题是：**模型原来已经能按前／左／右指令选对目标，在学会后格后，普通经验回放是否仍出现可复核的旧指令目标替代？**

例子：同一物理初态、同一句“放到前格”，R0放对；学习后格后的模型仍能抓放，但把书送到后格。这样的前后配对变化，比“成功率下降”更接近我们想研究的目标选择损伤。

抓空、掉落、超时没有完成，也可能是能力损伤，但不能直接当作目标绑定错误。R0本来不会做，更不能叫持续学习遗忘。

原完整方法中的功能分解、干预、差分蒸馏、覆盖选样都属于后续候选。先验证现象；若现象不成立，应接受这个设置的负结果，不继续调到出现所需失败。当前阶段路线及此前的方法评议见 [原最小起步审核计划](参考方案/2026-10-21_v3_审核与最小起步计划.md)。

### 4.4 进一步诊断与未解决问题

1. **专家回放不是全通过。** front/left/back各3条动作回放均曾达到对应目标；right/demo_0和right/demo_2没有达到，right/demo_1达到。总计10/12曾成功；12条保存终态恢复后的目标判据全部正确。报告的pass表示限定范围的判据/接口核验，不表示全部示范可完美重放。
2. **只恢复45维状态不够。** 复现演示必须恢复其XML场景、重置仿真和控制器相关状态；原XML带旧机器资产路径，代码已重映射资源路径，几何保持不变。不能随意拿新reset场景加载旧状态后比较回放。
3. **多指令复位已核对。** 同一canonical XML与front来源初态用于三指令；已检查的9个复位状态一致。资格20个初态与旧训练演示起点未重复，最小距离约0.1355。这只是起点不重复核验，不等于证明所有数据统计独立。
4. **未发现明显相机方向不一致。** 四任务demo_0原图与恢复仿真原图更接近，额外旋转误差明显更大；训练转换和部署都使用相同180度旋转。不能仅据此认定全部视觉/时间对齐问题都排除。
5. **动作离线误差确实降低。** 固定每目标24条训练记录、24条验证记录，同噪声比较：基础模型/3000步/6000步的验证XYZ前10动作MAE约0.282/0.151/0.133；对应验证FM loss约3.479/0.697/0.679。这里是控制器动作尺度，不是米；单噪声小样本不够判定过拟合或泛化水平。
6. **裁剪次数不能直接代表接口错误。** 离线检查主要越界发生于夹爪维度，部分平移也有少量越界；闭环旧日志只累计“任一维被裁剪”的步数，后续诊断宜分维记录。
7. **时序仍需谨慎核对。** 上游生成示范时观测与动作的保存顺序有时序细节；本轮沿用原始索引，没有为了提高结果任意挪动动作标签。后续如改，先拿原始状态/动作重放证据验证，并另立协议版本。

## 7. 建议同学了解并讨论的调整

以下均是建议，**没有执行、没有替代原方案**。同学可以提出不同选择，但应先写清证据、改变的变量和验收标准。

| 优先级 | 问题与证据 | 建议与需要决定的内容 |
|---|---|---|
| P0 | R0旧能力不稳；专家动作回放也不是12/12成功 | 先确认固定轨迹的学习→闭环执行能否接通，或先定位回放差异；不要直接进入FT/ER |
| P0 | 三初态要求3/3，比完整开发8/10更严格，可能误筛候选 | 讨论是否把3初态仅作诊断，按预先锁定的10初态开发规则选点；改动写成新协议版本，保留旧结果，不追溯宣称旧筛查已通过 |
| P1 | 训练只曝光36000条记录，显存分配约3.1GiB | 更多训练量可能有用，但不是已证明原因；若改batch或步数，先固定起点、曝光量、学习率与上限，避免同时改多个变量 |
| P1 | 曾成功后继续动作导致终态失败 | 保留first/ever/terminal分别报告；讨论400步时限与任务停止规则的研究含义，不能见结果后只挑更好看的指标 |

| P2 | 完整方案含差分蒸馏与覆盖选样，但尚无现象证据 | 暂不投入选样器；先做普通ER与完整蒸馏控制。若共同分量恢复更有用，应修正“仅保护差分”的假设 |
| P2 | 冻结VLM，更新主要发生在动作后端 | 后续表述应是语言条件对动作/目标选择的控制变化，不能直接称上游语义表征遗忘 |

关于初筛的一个具体备选：如果完整开发门槛是8/10，首3回合有1或2次成功时，剩余7回合仍有可能达标；首3回合全失败才已不可能达标。可以据此设计不改变8/10门槛的顺序评估，减少不必要的额外3/3要求。此方案尚未采纳，也不允许用资格集决定是否采纳。

单任务诊断已有一份具体候选：[下一轮单任务诊断_待确认.md](证据/r0_20261021_174358/下一轮单任务诊断_待确认.md)。建议使用已成功专家回放、且在训练划分内的front/demo_1，从基础模型开始，最多2000步，500/1000/2000步检查，同一XML与初态、5个推理噪声种子，4/5终态正确即停止。实现和训练**均未启动**，同学可先评判这个诊断是否值得做。

这里5个推理种子不是5个独立训练种子；同一初态的成功也不是泛化证据。如果诊断通过，再讨论三目标训练量；如果不通过，沿动作预测、原始控制回放、执行时序和状态漂移排查，不能直接归因于方法失效。

## 8. 后面继续主方案时的验收顺序

1. **旧能力**：开发选点后，一次独立资格检查。每旧目标16/20是操作门槛，不等于统计上已证明真实成功概率至少80%。需要额外独立复核时提前预留样本。
2. **新能力**：FT/ER各自学后格，确认相比R0有实际增益；没学会N1时不解释“新学习导致旧能力损伤”。
3. **前后配对**：锁定同一初态、相同指令、推理种子和控制配置，比较R0→FT及R0→ER。另做少量同权重R0→R0冻结重复对照，排查仿真/推理波动。
4. **失败归类**：以四目标判据区分正确、错误目标、未完成、歧义，同时记录首次/曾经/终态，重点看R0做对而更新模型做错目标的转移。
5. **按结果决定是否继续**：只有FT坏而ER稳，结论是普通回放在本设置有效；ER学会N1且仍有可复核的目标替代，再进入机制；两条都稳，接受负结果。
6. **方法验证**：在上述证据支持后再比较差分保护与完整蒸馏等控制；保持数据/训练预算公平，覆盖选样放最后。
