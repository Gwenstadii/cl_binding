# 同指令三目标80步交接与控制方向

全FT4与R0同指令80步→FT4，各左／前／右4回合，共24条。20条为历史轨迹核验重放，4条Right交接为新增。Right的R0前段没有任务训练资格；不切换指令，也不把三条指令当作同一个交接状态。

- `results.csv`：6行到达及终态结果。
- `directions.csv`：10/20/40步命令、末端、书本与抓持，72行。
- `axis_motion.csv`、`paired_command_vectors.csv`：事后轴向分解和世界控制向量对照，不修改主指标。
- `evaluation/events.jsonl.gz`：全部9600步动作、位置、原生控制目标、姿态、抓持与接触。
- `audit.json`：服务器审计含24条原视频完整解码。
- `audit_local_v1.json`：本地全部数值一致；视频解码在服务器完成，本地另核对哈希。
- `comparison_manifest.json`：12条并排视频核验。

24条原视频及12条并排视频在本地 `video/2026-10-30_同指令80步对比/`，不入Git。原服务器`evaluation/videos`保留原视频，manifest列其全部哈希。对缺失视频的纯Git克隆不能声称做完视频哈希验收；需要取回视频或在原服务器运行审计。
