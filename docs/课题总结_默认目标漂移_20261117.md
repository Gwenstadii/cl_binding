# 默认目标漂移课题总结（截至 2026-11-17）

一句话：SmolVLA 在 LIBERO 上顺序微调学新任务后，旧指令会被改道到新目标；本课题用 K1–K22 二十轮预登记实验把这个现象拆到了机制层，锁死两条规律——**新任务被写进与指令无关的共同响应**、**旧指令的身份信号完好只是被压细并混入杂音**——目前正沿"这两样能不能不从旧模型来"做探索（K23，今日启动）。汇报对象：张怀东老师。

## 1. 课题设定

- 模型与环境：SmolVLA（flow-matching 动作头，50×7 动作块），LIBERO 仿真，三个任务族：书架 SCENE2、书架 SCENE1B、碗 LIBERO-Goal。旧指令 A/B（书架：左/前；碗：灶台/柜顶），新任务 N（右 / 放盘子）。
- 基本范式：父模型（旧 A+B 任务）→ 续训（只学 N，FT4 12k 步）→ 测旧指令去向。核心指标：**成对分流 /20**（同一物理初态下，A 先到 A 目标且 B 先到 B 目标）。
- 主线证据标准：预登记（判定规则先于结果锁定）、多父模型种子、全新初态、修订披露。
- 代码与数据：全部在 3090 `/home/lzx/cl_binding_stage2a`（仓库）与 `/home/lzx/cl_binding/.server/`（各轮实验）；2080 上只放汇报文档。

## 3. 已锁定的两条核心发现

**发现一：顺序微调把新任务写成了与指令无关的共同响应偏移。**
原生续训与"保留新共同响应、只放大区别"在 7 条线（3 任务族、3 对独立种子、全新初态、快照/复位两种接手）上全部 0/20。学右线上，在旧共同响应下把新任务指令原样给续训模型，0–1/20 去新目标——新任务就住在共同响应里（r1_front 例外：仍挂在指令上，原因未知）。

**发现二：旧指令的身份信号完好，只是幅度被压细并混入方向外的有害杂音。**
续训模型对旧指令的输出投到旧区别方向上，符号正确率 ≥99.4%（每线 2400 次查询）；幅度缩到旧的 0.08–0.27。只保留平行分量、配上旧共同响应，7 条线 11–20/20，全部接近父模型水平；只留方向外分量 0–6/20。等价说法：让续训模型"说出是哪条指令"（只取符号），交给旧执行机构，就能恢复。

配套负结果（都做过、都不成立）：指令相似度非原因（K3）；语言/注意力补丁非语义存储（K4、K10–K13）；训练侧干预无效或定位不细（K18）；机制式保持项不如普通回放（K19）；路由与桥接不稳（K20）；"幅度足够"不普遍（K14→K21/K22 更正）。

## 4. 局限（评审视角自认）

- 共同响应 μ 和方向轴 d 都来自旧模型，续训模型只贡献一个标量——这是**读出证据，不是修复方法**。
- 单模型（SmolVLA）、单仿真（LIBERO）；c_s2b 父模型本身偏弱（12/20），该线数字仅参考。
- r1_front（学前）与四条学右线在"新任务写在哪"上不一致，尚无解释。
- 11-12 以 MEAN 评委标准看：原"训练更新→失败类型"机制链写法走不通（3/10），已按建议收窄为上述两条规律的短文路线。
